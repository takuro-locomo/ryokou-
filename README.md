# ryokou — 旅行の計画・日程検討

旅行の行き先・日程・予算・予約状況をまとめるリポジトリ。

## フォルダ構成

| フォルダ | 内容 |
|---|---|
| `00_要件.md` | いつ・誰と・どこへ・予算など、計画の前提（最初に埋める） |
| `01_候補/` | 行き先・宿・移動手段の候補比較 |
| `02_日程案/` | 日程案（A案/B案…）。確定したら `確定_日程表.md` に昇格 |
| `03_予約/` | 予約済みの控え（番号・金額・キャンセル期限） |
| `99_メモ/` | 持ち物・気づき・URLメモ |

## 進め方

1. `00_要件.md` を埋める（未定は「未定」でOK）
2. 候補を `01_候補/` で比較 → 行き先を決める
3. `02_日程案/` に案を作り、比較して確定
4. 予約したら `03_予約/` に控えを残す

⚠️ 予約番号・氏名・カード情報などの個人情報はコミットしない（`03_予約/` は要注意）。
