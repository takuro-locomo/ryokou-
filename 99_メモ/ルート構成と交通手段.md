# 黒部ダム日帰り（長野側・扇沢起点）— 場所の位置関係と交通手段

作成日: 2026-09-01（運賃・所要は公式2026年版）

## 全体像（西←→東）
```
[富山側]                                                        [長野側]
立山駅 ─ケーブル7分─ 美女平 ─高原バス50分─ 室堂 ─電気バス10分─ 大観峰 ─ロープウェイ7分─ 黒部平 ─ケーブル5分─ 黒部湖 ─徒歩15分(ダム堰堤)─ 黒部ダム ─電気バス16分─ 扇沢 ═車24分═ 大町 ═車1.5〜2h═ 長野
 475m            977m   (弥陀ヶ原1,930m・天狗平2,300m)  2,450m         2,316m          1,828m          1,455m                    1,470m           1,433m       約700m        約360m
```
- **車で行けるのは扇沢まで**（長野側）。扇沢〜立山駅の間は一般車進入禁止で、アルペンルートの乗り物を乗り継ぐ
- 長野側から入ると **黒部ダムが最初**、室堂が最奥（片道4本乗り継ぎ）。富山側から入ると順序が逆
- 日帰りで「戻る」場合は同じ乗り物を逆順に戻る（往復きっぷ）

## 区間ごとの交通手段
| 区間 | 手段 | 所要 | 運賃（大人・片道） | メモ |
|---|---|---|---|---|
| 長野市 → 大町市街 | **自家用車**（一般道：白馬長野有料道路 or 小川村経由） | 1.5〜2h | 通行料〜¥500 | 高速不要。前泊するなら大町温泉郷（扇沢まで15分）か白馬（40分） |
| 大町 → 扇沢 | **自家用車**（県道45号・大町アルペンライン） | 24分 | — | 扇沢駐車場: 無料230台＋有料350台（12h¥1,000）＋臨時600〜800台（8km手前・シャトル15分）。連休は6時台で無料満車 |
| 扇沢 → 黒部ダム | **関電トンネル電気バス**（関西電力） | 16分 | ¥1,800（往復¥3,200） | 破砕帯を通る。ここだけ関電の運行、以降は立山黒部貫光 |
| 黒部ダム → 黒部湖 | **徒歩**（ダムの堰堤上を歩く） | 15分 | 無料 | 観光放水（7:00〜16:30）・ダム展望台（階段220段）・レストハウス（ダムカレー）はこの区間 |
| 黒部湖 → 黒部平 | **黒部ケーブルカー**（全線地下） | 5分 | ¥1,540 | |
| 黒部平 → 大観峰 | **立山ロープウェイ**（支柱なし1.7km） | 7分 | ¥1,960 | 紅葉・黒部湖の俯瞰。大観峰は展望台のみ（散策不可） |
| 大観峰 → 室堂 | **立山トンネル電気バス**（立山直下） | 10分 | ¥2,200 | 室堂が最高地点2,450m |
| 室堂 → 天狗平 → 弥陀ヶ原 → 美女平 | **立山高原バス** | 天狗平5分／弥陀ヶ原15分／美女平50分 | 室堂⇔天狗平¥530／⇔美女平¥3,300 | 途中下車できるのは弘法・弥陀ヶ原・天狗平のみ |
| 美女平 → 立山駅 | **立山ケーブルカー** | 7分 | ¥1,090 | 立山駅から先は富山側の車道 |

※ 扇沢⇔室堂 往復は通し料金¥12,300（早割¥11,300）で、上の4本を個別に買うより安い。

## 日帰りモデル（扇沢起点・室堂まで）
```
 6:00 扇沢駐車 → 6:30 電気バス → 6:46 黒部ダム（放水は7:00〜・堰堤徒歩）
 → 7:50 黒部湖 → ケーブル → 黒部平 → ロープウェイ → 大観峰 → 電気バス → 9:00頃 室堂
 → 室堂で3〜4h（みくりが池・雷鳥沢・昼食）
 → 13:00 室堂発（13〜15時が混雑ピークなので早めに）→ 14:30 黒部ダム（ダムカレー・展望台）
 → 15:30 電気バス → 15:50 扇沢 → 車で大町・長野へ（〜18:00 長野）
```
黒部ダムだけなら「扇沢⇔黒部ダム 往復¥3,200・所要2〜3h」で午前中に終わる。

## 富山側との違い（参考）
- 富山側（立山駅）から入ると **称名滝・美女平の杉・弥陀ヶ原** を通り、黒部ダムが最奥になる
- 長野側から入ると **黒部ダムが手前** で、室堂まで行っても行かなくても組みやすい。今回はこちら
